# Recto

保留版式的文档翻译工具：上传 PDF、图片或扫描件，翻译后每段文字回到原来的位置，字号、颜色、对齐方式都保持不变。图片里的文字也会一起翻译。

整个工具在浏览器里运行：解析和 OCR 在本地完成，翻译用用户自己的 API Key 直接调用 Claude 或 DeepSeek，不需要后端。

## 功能

- **三种识别方式**，按页自动推荐，也可以手动切换：
  - 文字层：电子版 PDF 直接读取文字层
  - 整页 OCR：适用于图片和扫描件
  - 文字层 + 图片内文字：适用于带插图标注的说明书
- **结构化去字**：PDF 页面会额外渲染一次，渲染时跳过所有绘制文字的指令，得到一张没有文字的背景。原文就是从这张背景上擦除的，所以渐变、底纹、压在图上的文字都不会留下色块。
- **样式还原**：每段文字的颜色取原图与无字背景之间有差异的像素；背景色取边框颜色的众数；对齐方式（左、中、右、两端）根据各行的边缘来判断。
- **自适应排版**：中日文逐字断行，西文按词断行；行首避开标点；放不下时逐步缩小字号，缩到最小仍放不下的段落会标为"放不下"。
- **翻译**：可选 Claude（Opus / Sonnet / Haiku 5.5）或 DeepSeek（Flash / V4 Pro），两家的 Key 分开保存。按段落发送 JSON，拿回逐段译文：Claude 用结构化输出，DeepSeek 用 JSON 模式并关闭思考，遇到空回复会自动重试一次。模型会保留数字、型号和单位，支持术语表，并把上一页的译文作为上下文传入，保证前后一致。
- **AI 识别（可选，按页计费）**：扫描件和图片可以交给视觉模型读字。先用本地的行检测（二值化 + 连通域）找出每一行，同时排除插画、注音和目录引导点；然后把每一行单独裁出来，竖着排成带编号的“行清单”图，让模型逐行抄写。这样模型不会把文字安到相邻的框上。识别结果按“文件 + 页码 + 识别方式”缓存在浏览器里，刷新页面或重新打开同一个文件都不用再付一次识图的钱。行的位置以本地检测为准，所以不会漏行，译文也会回到原来那一行；注音会随原文一起擦掉。支持 Claude 全部三个模型和 DeepSeek（识图固定用 deepseek-flash）。关闭时使用本地 Tesseract（日文 + 中文 + 英文）。
- **预检提示**：
  - 没有文字层，建议改用 OCR
  - 字体编码损坏
  - 有旋转文字，会保留原文
  - 版面复杂，需要重点检查
  - 译文放不下
  - OCR 置信度低
- **审校**：可以切换译文、原文、对照三种视图。点击页面上的任意文字框会定位到对应段落，每段可以修改原文和译文、调整字号、单独重新翻译。
- **导出**：导出 PDF（按原页面尺寸，图片型）或当前页 PNG。
- **演示模式**：内置一份英文示例说明书和对应的简体中文译文，不填 Key 也能完整体验整个流程。

## 首页与视觉

- 首页是一段滚动叙事：同一页说明书随着滚动依次被框出文字、擦掉原文、排上中文，最后左右对照审校。实现用的是 Lenis 平滑滚动加 GSAP ScrollTrigger（scrub）。画框在三种布局之间切换：首屏位置、全屏、右半屏，用 clip-path 做转场。画面推近、拉远的"镜头"用 transform 计算；标题用 SplitText 拆成单字，随滚动逐字着色。
- 窄屏或系统开启"减少动态效果"时，自动换成静态分章版本，每一章配一张定格插画。
- 视觉风格：方格纸底、颗粒噪点、无衬线大标题、建筑师手写体标注，深蓝加橙色点缀。字体用的是 Hanken Grotesk、思源黑体、Architects Daughter 和 Geist Mono。

## 运行

```bash
npm install
npm run dev
```

其他命令：

- `npm run build`：生成静态站点到 `dist/`。`base` 设为相对路径，可以直接放到 GitHub Pages。
- `npm run sample`：重新生成示例说明书（`public/sample/`）和演示译文表（`src/lib/sample-dict.json`）。
- `npx tsx scripts/check-translate.ts`：离线检查发给 Claude 和 DeepSeek 的翻译、识图请求格式，以及响应解析和错误处理，不联网。
- 开发时可以在浏览器控制台运行 `import('/src/dev/testpages.ts')`。里面有三张模拟扫描页（目录、人物、版权页），以及画行框、打分、模拟 DeepSeek 回复等工具。

## 代码结构

| 文件 | 作用 |
|---|---|
| `src/lib/pdf.ts` | pdf.js 渲染页面（原图和无字背景各一份）、提取文字和字体样式、把文字分组成段落、页面分类 |
| `src/lib/lines.ts` | 行检测：二值化、连通域、把字串成行；排除插画、注音、引导点 |
| `src/lib/aiocr.ts` | AI 识别：生成带编号的行清单图，以及 Claude / DeepSeek 两种识图实现 |
| `src/lib/ocrcache.ts` | OCR 结果缓存（IndexedDB） |
| `src/lib/ocr.ts` | OCR 入口：AI 识别，或 Tesseract 稀疏模式；把行组织成段落，生成擦除框 |
| `src/lib/textblock.ts` | 行和段落分组、软换行与硬换行判断、对齐检测、判断一段是否需要翻译 |
| `src/lib/color.ts` | 背景色和文字色取样 |
| `src/lib/layout.ts` | 断行、字号自适应、擦除原文并绘制译文 |
| `src/lib/translate.ts` | Claude 翻译（结构化输出 + 服务端回退）、DeepSeek 翻译（OpenAI 兼容接口）和演示模式的翻译器 |
| `src/lib/pipeline.ts` | 识别 → 翻译 → 溢出检查的流水线，以及实时提示 |
| `src/lib/export.ts` | 用 pdf-lib 导出 PDF / PNG |
| `src/landing/` | 首页：滚动叙事（`Landing.tsx`）、分层文档插画（`DocStage.tsx`）、样式（`landing.css`） |

## 已知限制

- 导出的 PDF 是图片型，文字不能选中或搜索。可选中的文字导出需要内嵌目标语言字体，放在后续迭代。
- 旋转和竖排文字暂时保留原文。
- 识别语言选"自动"时，OCR 按英文识别。非拉丁文字的图片请手动选择原文语言。
- 译文排版使用设备上已安装的字体，不同系统的效果会略有差别。
